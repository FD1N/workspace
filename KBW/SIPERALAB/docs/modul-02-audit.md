# Audit Modul 2 Semantic HTML dan Formulir

## Sebelum perbaikan
| Halaman/elemen | Bukti | Rencana perbaikan |
|---|---|---|
| Katalog masih berupa ul/li | peralatan.html DOM | Ubah menjadi section + article |
| Form belum tersedia | peminjaman.html file baru | Buat form lengkap |

## Setelah perbaikan
- [x] Landmark halaman masuk akal (header, nav, main, footer).
- [x] Hierarki heading logis (h1, h2, h3).
- [x] Minimal tiga item katalog lengkap (Multimeter, Router, Kamera).
- [x] Label dapat diklik dan fokus berpindah ke input.
- [x] Field penting memiliki atribut name.
- [x] Submit kosong memunculkan validasi browser.
- [x] Urutan Tab navigasi keyboard logis.
- [x] Validator tidak menampilkan error utama.
